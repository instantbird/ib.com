Télécharger le code source

Étant donné qu'Instantbird est un projet open source, vous pouvez en télécharger le code source et le modifier librement.

Quoi de neuf ?

  • Les discussions peuvent désormais être mises en attente :
    • Une discussion peut être mise en attente à partir du menu contextuel de l'onglet de la discussion. Les discussions en attente sont listées en haut de la fenêtre des contacts, où il est facile de les rouvrir avec un double clic.
    • La fermeture d'un onglet de conversation ne peut plus vous faire manquer des messages : lorsque l'onglet d'une discussion avec des messages non lus est fermé, la discussion est automatiquement mise en attente au lieu d'être fermée.
    • La fermeture d'un onglet de salon de discussion vous permettra de mettre sa discussion en attente au lieu de la quitter.
    • Si un nouveau message arrive dans une discussion en attente, son onglet réapparaîtra automatiquement. (Pour les salons de discussion, ceci ne se produira que si votre pseudo est mentionné.)
    • Le nombre de messages non lus dans chaque discussion en attente est clairement indiqué, ce qui sera utile pour les salons IRC sur lesquels vous n'êtes pas actif !
  • Support de la barre des tâches amélioré pour Linux et Windows :
    • Restaurez la liste de contacts avec un clic simple sous Linux.
    • L'icône d'Instantbird est visible dans la barre des tâches même lorsque l'application n'est pas minimisée.
  • Support de Twitter amélioré :
    • Les entités de Twitter (@mentions, #hashtags, et liens raccourcis) sont désormais supportées.
    • Vous pouvez maintenant retweeter et répondre aux messages (en utilisant le menu contextuel).
    • Vous pouvez vous abonner et vous désabonner aux twitteurs directement à partir du menu contextuel de leurs tweets.
  • IBM Lotus Sametime est désormais supporté, suite à la demande générale.
  • Les participants aux discussions ont désormais des infobulles.
    • Les informations whois sur IRC sont obtenues et affichées automatiquement.
  • Le complètement des pseudos IRC, des noms d'utilisateurs de Twitter, et des commandes avec la touche Tab.
  • La nouvelle API du gestionnaire d'interruptions permet aux développeurs de modules complémentaires de facilement réduire les nuisances :
    • Les événements peuvent être filtrés en fonction de leurs détails (type, source, etc.) afin de déterminer les actions qui peuvent se produire.
  • Les paramètres par défaut d'ICQ ont été mis à jour pour fonctionner avec leurs nouveaux serveurs.
  • Les commandes inconnues ne sont désormais plus envoyées dans les salons de discussion IRC/XMPP.
  • Mises à jour: Instantbird 1.1 se est basé sur libpurple 2.10.0 et Mozilla 7.0.1, ce qui apporte d'intéressantes nouvelles possibilités pour les développeurs de modules complémentaires.
  • Stabilité améliorée: les rapports d'incidents de la version 1.0 et des compilations nocturnes ont été pris en compte pour corriger des bugs qui causaient de fréquents plantages.
  • Et plus encore… lisez le ChangeLog complet pour plus de détails à propos des 138 changements de code depuis Instantbird 1.0.
