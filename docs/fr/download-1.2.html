Télécharger le code source

Étant donné qu'Instantbird est un projet open source, vous pouvez en télécharger le code source et le modifier librement.

Quoi de neuf ?

  • Le visionneur d'historique montre désormais les conversations telles qu'elles apparaissent dans leur fenêtre de discussion, grâce à un nouveau format de fichiers d'historique basé sur JSON qui enregistre des métadonnées avec le texte de la conversation.
  • Bonjour est désormais supporté (requiert les Services d’impression Bonjour sur Windows or Avahi sur Linux).
  • L'interface des salons de discussion a été améliorée :
    • Meilleur complètement avec la touche Tab, voir l'article sur notre blog pour plus de détails.
    • Il est plus facile de voir qui est actif, du fait que seuls les pseudos ds participants qui ont parlé sont colorés dans la liste des participants.
  • Améliorations d'IRC :
    • Les canaux sont automatiquement rejoints après les reconnexions.
    • Instatbird suit le statut des contacts IRC de manière plus précise en utilisant les commandes WATCH et MONITOR, si elles sont supportées.
    • Les messages de ChanServ sont montrés dans le canal auquel ils se rapportent.
    • Plus de messages bruyant de NickServ qui vous interrompent après une identification automatique à la suite de la connexion.
  • Les mots de passe sont désormais enregistrés dans le gestionnaire de mots de passe de Mozilla pour plus de sécurité. Tout comme dans Firefox, il est possible de les protéger en utilisant un mot de passe principal.
  • Créez de nouveaux comptes plus facilement maintenant que l'assistant de création de compte offre une liste des réseaux les plus populaires, avec l'option de montrer tous les réseaux supportés.
  • Meilleure intégration dans la barre des tâches : vous pouvez désormais changer votre statut directement à partir du menu contextuel de l'icône de la barre des tâches.
  • Reprenez facilement vos conversations là où vous les avez laissées : la position du premier message non lu est marquée visuellement (et vous pouvez y accéder rapidement en pressant Alt-PgPrec/PgSuiv ou avec un glissement de doigts).
  • Lorsqu'une longue conversation est restaurée, une barre de progrès s'affichera désormais au lieu de bloquer l'interface jusqu'à ce que tous les messages soient chargés..
  • Les messages déjà lus (ou « de contexte » sont maintenant différenciés des nouveaux messages (lorsque la conversation est restaurée après avoir été mise en attente) dans tous les styles de messages fournis par défaut. Aussi, ces styles respectent désormais les réglages de police définis dans Préférences > Contenu.
  • La navigation avec le clavier a été améliorée en permettant le défilement à partir d'une boîte de texte (vide) : utilisez simplement les touches fléchées, Page Précédente/Suivante, ou Début/Fin ! Il y a également de nouveaux raccourcis pour mettre une discussion en attente (Échap) et pour afficher l'historique (Ctrl+Shift+H, comme pour afficher l'historique sur Firefox).
  • De majeures améliorations d' l'accessibilité ont été apportées aux nouveaus messages, aux groupes de contacts, et aux contacts.
  • Pour les développeurs de modules complémentaires :
    • Contrôle plus précis des préférences de son : par exemple Advanced Sound Controls.
    • Possibilité de réarranger la liste de contacts : par exemple Sort By Status.
    • Il est maintenant possible d'ajouter de nouveaux protocoles en utilisant JavaScript : par exemple VZnet Chats.
  • Sous le capot
    • Nous avons désormais nos propres implémentations extensibles en JavaScript pour :
      • Facebook Chat et Google Talk, basés sur notre propre plugin de protocole XMPP (de Google Summer of Code 2011).
      • IRC
    • Mises à jour : Instantbird 1.2 est basé sur Mozilla 14.0.1 qui apporte de nouvelles possibilités pour les développeurs de modules complémentaires et utilise libpurple 2.10.4.
    • La licence pour la majorité du code a été mise à jour vers la Mozilla Public License (MPL) 2.0, les compilations officielles d'Instantbird 1.2 sont distribuées en accord avec les termes de la Licence publique générale GNU 2.0 ou ultérieure.
    • Nous utilisons désormais libqq-pidgin pour QQ étant donné que QQ n'est plus inclut dans libpurple.
    • Des changements de plate-forme nous ont forcés à cesser le support de Windows 2000 et Windows XP jusqu'au Service Pack 2. Veuillez passer à Windows XP SP2 ou à une version ultérieure.
  • Et plus… Lisez le ChangeLog complet pour plus de détails à propos des 403 changements de code depuis Instantbird 1.1.

Problème connus

  • Gestion des certificats auto-signés et invalides (bug 1292).
