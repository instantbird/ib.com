Configuration minimale

Ci-dessous est la configuration minimale requise pour pouvoir utiliser Instantbird.

Windows

  • Systèmes d'exploitation: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128Mo de RAM
  • 50Mo d'espace sur le disque dur

Mac

  • Systèmes d'exploitation: Mac OS X 10.6 (Snow Leopard) ou ultérieur
  • 256Mo de RAM
  • 100Mo d'espace sur le disque dur

Linux

Instantbird requiert au minimum les librairies suivantes pour fonctionner sous Linux :

  • GTK+ 2.18 ou ultérieur
  • GLib 2.22 ou ultérieur
  • Pango 1.14 ou ultérieur
  • X.Org 1.0 ou ultérieur
  • libstdc++ 4.3 ou ultérieur

Veuillez noter que cette liste peut être différente pour les paquets fournis par les distributions de Linux.
