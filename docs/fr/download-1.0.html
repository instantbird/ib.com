Télécharger le code source

Étant donné qu'Instantbird est un projet open source, vous pouvez en télécharger le code source et le modifier librement.

Quoi de neuf ?

  • Fenêtre de contacts rénovée :
    • Fusion de contacts: Si vous parlez à la même personne sur plusieurs réseaux de messagerie instantanée, vous pouvez désormais combiner les noms d'utilisateur de chaque réseau de cette personne en un seul contact. Lorsque vous ouvrez une nouvelle conversation, le nom d'utilisateur qui est en ligne sera sélectionné automatiquement et la fenêtre de discussion basculera automatiquement vers le nom d'utilisateur correspondant si la personne change de réseau de messagerie instantanée.
    • Tags: Les tags seront utilisés pour remplacer les groupes dans la liste de contacts. Les tags peuvent être cachés en cliquant le « x » sur la droite de la liste de contacts, tous les contacts de cette liste seront transférés automatiquement ver le tag « Autres Contacts, » qui est affiché en bas de la liste de contacts
    • La liste de contacts peut désormais être…
      • fermée sur Mac sans quitter Instantbird ; elle peut être réouverte à partir du Dock.
      • minimisée sous Windows et Linux. Par défaut fermer (cliquer sur le « x ») la liste de contacts la minimisera dans la barre des tâches, ce qui peut être changé dans les préférences.
    • Les utilisateurs peuvent désormais changer leur icône de contact ainsi que le nom à afficher de leurs comptes directement à partir de la liste de contacts.
    • La liste de contacts est rangée par ordre alphabétique (les groupes et les contacts sont rangés.)
    • Meilleures animations.
  • Support de Twitter: Lorsque le compte Twitter est connecté, une conversation s'ouvre automatiquement pour l'historique. Si la conversation est fermée par l'utilisateur, elle est rouverte automatiquement lorsqu'un nouveau message est reçu. L'utilisateur devrait déconnecter le compte à partir du gestionnaire des comptes afin d'éviter que les nouveaux messages soient affichés.
    Il y a une option avancée de « suivi » vous permettant de spécifier des mots-clés à suivre. C'est une liste de mots-clés séparés par des virgules. Les virgules signifient OU, une espace à l'intérieur d'un mot-clé signifie ET.
  • Nouvelle barre d'outils d'information en haut de l'interface de conversations, montrant l'icône du contact, le nom à afficher et le statut actuel de votre contact. De plus, vous pouvez changer le réseau de messagerie instantanée utilisé pour la conversation en cliquant sur l'icône de protocole.
  • Le style des onglets de conversations a été mis à jour pour correspondre à celui de Firefox 4, et les utilisateurs de versions récentes de Windows apprécieront des effets de verre Aero.
  • Bubbles, le thème de messages par défaut, a reçu de nouvelles caractéristiques relatives au temps, voir notre article de blog pour plus de détails.
  • (Windows 7 uniquement) Support de la jumplist pour changer de statut rapidement.
  • Sous le capot : les plugins de Protocole peuvent désormais être implémentés en JavaScript.
  • Tout un tas d'améliorations mineures, parmi lesquelles :
    • Vous pouvez désormais allez à l'onglet n en utilisant <modifieur>+<n> sur la fenêtre de discussion, où <modifieur> est Contrôle sous Windows/Linux et Commande sur Mac.
    • Une commande d'aide ('/help') a été ajoutée afin de voir rapidement et facilement les commandes disponibles dans la conversation actuelle.
    • Un statut inconnu est désormais différencié d'un statut hors ligne avec des icônes différentes.
    • Variante sombre du skin « Simple. »
  • Mis à jour: Instantbird 1.0 se base sur libpurple 2.7.11 et Mozilla 2.0.1 ce qui apporte de superbes nouvelles possibilités pour les développeurs de modules complémentaires (par exemple, les modules sans redémarrage).
  • Stabilité améliorée: nous avons utilisé les rapports d'arrêts soudains que nous avons reçus des versions 0.2 et 0.3, ainsi que des versions quotidiennes pour corriger des bugs qui engendraient des arrêts soudains.
  • Et plus encore… lisez la Liste de changements complet pour plus de détails à propos des 329 changements de code depuis Instantbird 0.2).

Problème connus

  • Après avoir fermé l'historique Twitter, il ne peut pas être rouvert manuellement pour envoyer un tweet, il se rouvrira automatiquement lorsqu'un tweet sera reçu.
