    • Installation

    Est-ce qu'il faudra que je fournisse de nouvelles coordonnées à mes amis ?

    Non, avec Instantbird vous pouvez utiliser tous vos comptes de messagerie instantanée existants avec une seule application. Si vous utilisez déjà la messagerie instantanée, vous n'aurez pas à créer de nouveau compte pour commencer à utiliser Instantbird.

    Est-ce qu'Instantbird fonctionnera sur mon ordinateur ?

    Instantbird supporte actuellement Windows XP SP2 ou ultérieur, Mac OS X 10.5 ou ultérieur, et Linux. Voir la configuration minimale requise pour plus de détails.

    Que devrais-je télécharger pour obtenir la dernière version d'Instantbird ?

    Un lien de téléchargement sur la page d'accueil choisira automatiquement pour vous la version d'Instantbird qui semble la plus adaptée à votre système. Si vous voulez sélectionner manuellement votre système d'exploitation et votre langue, rendez-vous sur la page des téléchargements.

    Est-ce que je peux installer Instantbird sans être administrateur sur mon ordinateur ?

    Absolument !

    Est-ce que je peux installer Instantbird et garder mon client de messagerie instantanée précédent sur mon ordinateur ?

    Absolument ! Instantbird et les autres clients de messagerie instantanée peuvent coexister sur le même ordinateur sans poser de problèmes.

    Comment faire pour installer Instantbird sous Windows ?

    Instantbird pour Windows est livré sous forme d'installeur exécutable. Lancez simplement le ficher que vous aurez téléchargé, et laissez-le vous guider à travers le processus d'installation.

    Comment faire pour installer Instantbird sous Mac OS X ?

    Double-cliquez sur l'image disque Instantbird (un fichier dont le nom se termine en « .dmg ») que vous aurez téléchargé. Faites ensuite glisser l'icône d'Instantbird dans le dossier « Applications. »

    Comment faire pour installer Instantbird sous Linux ?

    Extract the content of the downloaded archive, and launch the file named "instantbird". If a popup dialog asks you if you want to edit or launch the file, select "launch".

    We currently only provide 32-bit builds. In order to run these on a 64-bit system, you will have to install the 32-bit compatibility libraries provided by your distribution. For example, on Ubuntu, install the package ia32-libs by running sudo apt-get install ia32-libs from the command line.

    Instantbird est-il portable (utilisable à partir d'une clé USB ?)

    Si vous lancez Instantbird à partir d'une clé USB, il enregistrera votre profil d'utilisateur sur le disque dur par défaut.

    Vous pouvez dire à Instantbird d'enregistrer votre profil d'utilisateur sur la clé USB en utilisant l'argument -profile sur la ligne de commande.

    Pour ce faire, faites un clic droit sur le fichier instantbird.exe et sélectionnez « Créer un Raccourci, » puis dans les propriétés du raccourci, éditez la cible et ajoutez-y -profile ./nom du dossier

    Mises à jour

    Que dois-je faire pour continuer d'utiliser la dernière version d'Instantbird ?

    Rien. Par défaut, Instantbird recherchera automatiquement des mises à jour et demandera votre permission de se mettre à jour si une nouvelle version est trouvée.

    Si cela ne vous plaît pas, vous pouvez le changer dans la fenêtre de préférences.

    Et si je veux mettre à jour tout de suite ?

    Il y a une option Rechercher des mises à jour dans le menu (accessible à partir du menu Aide) pour que vous n'ayez pas à attendre le message de mise à jour si vous savez qu'une mise à jour existe.

    Est-ce que je peux remplacer une version existante avec une version plus récente ?

    Oui.

    Mes modules complémentaires fonctionneront-ils encore après une mise à jour ?

    Les modules compatibles fonctionneront toujours après une mise à jour. Si un module complémentaire n'est pas compatible avec la nouvelle version d'Instantbird, celui-ci vous proposera de rechercher une version plus récente du module et de le mettre à jour.

    Si votre module complémentaire ne fonctionne plus après une mise à jour, vous pouvez en contacter l'auteur afin de savoir si une mise à jour est prévue.

    Désinstallation

    Comment désinstaller Instantbird ?

    Sous Windows, si vous avez utilisé l'installeur, vous pouvez désinstaller Instantbird à partir du panneau de configuration, tout comme n'importe quelle autre application.

    Dans certains cas, vous pouvez simplement supprimer le dossier Instantbird.

    La désinstallation d'Instantbird ne supprimera pas vos comptes, historiques, extensions ou autres modules complémentaires. Ces données sont stockées dans votre dossier de profil.

    Toute version d'Instantbird installée après la suppression d'Instantbird continuera d'utiliser les données dans ce dossier.

    Utilisation

    Est-ce que je peux utiliser plusieurs comptes à la fois ?

    Oui, vous pouvez être connecté à plusieurs comptes sur tous les protocoles supportés à la fois.

    Utilisez le gestionnaire des comptes (accessible à partir du menu Outils) pour ajouter un autre compte.

    Quels sont les protocoles supportés ?

    Currently Instantbird supports by default: AIM, Bonjour, Facebook Chat, Gadu-Gadu, Google Talk, Groupwise, ICQ, IRC, MSN, MySpaceIM, Netsoul, Odnoklassniki, QQ, Simple, Twitter, VKontakte, XMPP, Yahoo and Yahoo JAPAN.

    Des protocoles supplémentaires peuvent être installés comme modules complémentaires.

    Quand j'essaie de me connecter à mon compte Facebook, je reçois le message d'erreur Identifiant XMPP non valide. Quel est le problème ?

    Vous avez entré comme nom d'utilisateur l'adresse e-mail que vous utilisez pour vous enregistrer sur le site de Facebook. Facebook chat s'attend à ce que vous utilisiez votre nom d'utilisateur unique dans ce champ. Vous pourrez le trouver sur http://www.facebook.com/username/.

    Quand j'essaie de connecter mon compte Facebook, je reçois le message d'erreur Non Autorisé. Quel est le problème ?

    Vous devez activer les connexions XMPP à votre compte Facebook.

    1. Visitez Facebook Chat en étant connecté à votre compte Facebook pour activer l'accès XMPP.
    2. Fermez votre session sur le site de Facebook.
    3. Rouvrez votre session sur le site de Facebook.
    4. Connectez votre compte Facebook dans Instantbird (« Outils » > « Comptes » et cliquez sur le bouton « connecter » de votre compte Facebook) et la connexion devrait alors s'établir avec succès.

    Où est-ce que je peux trouver des modules complémentaires (extensions et thèmes ?)

    Vous pouvez rechercher des modules complémentaires à partir de l'onglet Obtenir des modules complémentaires du gestionnaire de modules complémentaires (accessible à partir du menu Outils) où vous trouverez quelques modules recommandés. Pour plus de modules, vous pouvez vous rendre sur le site des modules complémentaires d'Instantbird, où vous pourrez également trouver des modules complémentaires expérimentaux et écrire des critiques.

    Est-ce qu'Instantbird conserve un historique de mes conversations ?

    Oui, Instantbird crée des fichiers d'historique par défaut. Utilisez les options dans l'onglet vie privée dans le menu Préférences afin de les configurer à votre goût. Si vous voulez jeter un œil aux fichiers, vous pouvez utiliser le bouton ouvrir le dossier... dans le même onglet.

    Où sont les historiques conservés ?

    Le nom et chemin des fichiers d'historiques sont comme suit : chemin du profil/logs/protocole/contact ou nom d'utilisateur/date et heure.txt (remplacez les parties en italique avec les valeurs correspondantes).

    Où est mon dossier de profil ?

    Il se trouve à l'un des endroits suivants, selon votre système d'exploitation :

    Windows%appdata%\Instantbird\Profiles\ (copiez et collez ceci exactement dans le navigateur de fichiers de Windows)
    Mac OS X~/Library/Application Support/Instantbird/Profiles/
    Linux (Unix)~/.instantbird/

    Toute version d'Instantbird installée après avoir supprimé Instantbird continuera d'utiliser les donnés contenues dans ce dossier de profil.

    Est-ce que je peux accéder about:config pour ajuster certaines option?

    Bien que nous en décourageons l'usage, about:config est disponible à partir de l'onglet Avancé de la fenêtre de préférences.

    Développement

    Pourquoi faites-vous Instantbird ?

    Nous vous offrons Instantbird parce que nous croyons que la messagerie instantanée est une partie importante de votre vie en ligne.

    Quelle est la licence utilisée par Instantbird ?

    Instantbird is licensed to you under the terms of the GNU GPL license version 2.0 or later (because it uses libpurple which is GPL licensed). However, most of the source code is also licensed with the Mozilla Public License (MPL), version 2.0.

    Où se trouve le code source ?

    Un tarball du code source de chaque version publiée est disponible à partir de la page des téléchargements. Le code de développement le plus récent peut s'obtenir à partir de notre dépôt Mercurial en suivant les instructions de compilation.

    Qui fait Instantbird ?

    Nous sommes une petite équipe d'individus très motivés, mais nous espérons que beaucoup de gens, vous y compris, nous joindront pour améliorer davantage ce projet.

    Est-ce que Mozilla parraine le projet ?

    La fondation Mozilla ne nous a pas aidés financièrement.

    Le logo « Propulsé par Mozilla » sur notre page d'accueil signifie qu'Instantbird se sert de code et de technologies développés par la communauté Mozilla. Nous sommes très reconnaissants envers la communauté Mozilla en général pour les technologies extraordinaires sur lesquelles Instantbird se base.

    Comment puis-je participer ?

    Il y a plusieurs façons de participer au projet. Vous n'avez pas besoin d'être un programmeur pour nous aider. Voir nous aider.

    Est-ce que je peux vous aider à traduire dans ma langue ?

    Oui ! Voir la page de wiki à propos de la traduction pour plus de détails.

    Comment faire pour créer des modules complémentaires ?

    Voir la page de wiki à propos des extensions.

    Est-ce que les modules complémentaires pour Firefox/Thunderbird peuvent fonctionner sur Instantbird ?

    Pas en tant que tel, mais la plupart peuvent être adaptés. Voir la page sur le port d'extensions Firefox.

    Comment puis-je suivre les travaux de développement ?

    Pour être informé des nouvelles importantes, vous pouvez suivre notre blog.

    Si vous désirez suivre nos discussions, n'hésitez pas à nous joindre sur notre salon de discussion IRC : #instantbird sur le serveur irc.mozilla.org.

    Les versions quotidiennes sont produites chaque jour afin que les utilisateurs puissent nous aider à tester les fonctionnalités qui viennent d'être ajoutées. N'hésitez pas à les utiliser, mais faites attention ! Il se peut qu'elles ne soient pas stables, et si vous décidez de les utiliser, c'est pour nous aider à tester les nouvelles fonctionnalités, et non pas simplement pour vous vanter d'être le premier à avoir un nouveau jouet. Alors si vous y trouvez des bugs, veuillez les rapporter (rapporter un bug : ce qu'un rapport de bug devrait contenir) au lieu de vous plaindre.

    Qu'est-ce qui sera dans la prochaine version ?

    Voir le plan d'action.

    Quand-est-ce que la prochaine version majeure sortira ?

    Nous sommes très enthousiastes à propos de ce projet, et heureux que vous partagiez notre désir d'avancer aussi vite que possible. Toutefois, étant donnée la nature du développement de logiciels, il pourrait poser problème d'annoncer des délais, et nous pensons que le maintien de la qualité est plus important.
