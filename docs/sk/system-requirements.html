Systémové požiadavky

Nasledujúce požiadavky sú minimálne potrebné pre beh Instantbirdu.

Windows

  • Operačný systém: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128MB operačnej pamäti
  • 50MB voľného miesta na disku

Mac

  • Operačný systém: Mac OS X 10.6 (Snow Leopard) a novšie
  • 256MB operačnej pamäti
  • 100MB voľného miesta na disku

Linux

Instantbird vyžaduje aspoň nasledujúce knižnice pre beh na Linuxe:

  • GTK+ 2.18 alebo vyšší
  • GLib 2.22 alebo vyšší
  • Pango 1.14 alebo vyšší
  • X.Org 1.0 alebo vyšší
  • libstdc++ 4.3 alebo vyšší

Pre rôzne linuxové distribúcie sa môžu uvedené požiadavky líšiť.
