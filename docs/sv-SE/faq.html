    • Installation

    Kommer jag att behöva förse mina vänner med ny kontaktinformation?

    Nej, med Instantbird kan du använda alla dina befinliga snabbmeddelandekonton i ett och samma program. Om du redan använder snabbmeddelanden, behöver du inte skapa nya konton för att börja använda Instantbird.

    Kommer Instantbird att fungera på min dator?

    Instantbird stöder för närvarande Windows XP SP2 eller senare, Mac OS X 10.5 eller senare, och Linux. Se systemkrav, för detaljerad information.

    Vad skall jag ladda ner för att få den senaste versionen av Instantbird?

    Nedladdningslänken på hemsidan, kommer automatiskt att välja den version av Instantbird som bäst stämmer överens med ditt system. Om du själv vill välja operativsystem och språkversion, går du till nedladdningssidan.

    Kan jag installera Instantbird utan att vara administratör på min dator?

    Ja, absolut!

    Kan jag installera Instantbird och ändå behålla min gamla meddelandeklient på min dator?

    Ja, det går bra! Instantbird och andra klienter kan samexistera på datorn utan att orsaka problem.

    Hur installerar jag Instantbird i Windows?

    Instantbird är paketerat i en körbar exe-fil, för Windows. Starta bara den nedladdade filen, och låt guiden leda dig genom installationsprocessen.

    Hur installerar jag Instantbird i Mac OS X?

    Dubbelklicka på Instantbirds den skivavbildning (en fil med filnamnstillägget ".dmg") du har laddat ner. Dra sedan Instantbird-ikonen till programmappen.

    Hur installerar jag Instantbird i Linux?

    Extrahera innehållet i det nedladdade arkivet, och starta filen som heter "instantbird". Om en popup-dialog frågar om du vill redigera eller starta filen, väljer du "starta".

    För tillfället tillhandahåller vi endast 32-bitars byggen. För att kunna köra detta på ett 64-bitars system, måste du installera ett 32-bitars kompatibilitetsbibliotek som tillhandahålles i din distribution. I t.ex Ubuntu, installerar du paketet ia32-libs genom att köra sudo apt-get install ia32-libs från terminal. I Ubuntu kan paketet också installeras från Programcentralen.

    Är Instantbird portabel (körbar från USB-minne)?

    Om du startar Instantbird från ett USB-minne, kommer det som standard att lagra din användarprofil på hårddisken.

    Du kan instruera Instantbird att lagra din användarprofil på USB-minnet genom att starta programmet med argumentet -profile.

    För att göra detta, högerklickar du på instantbird.exe och väljer "Skapa genväg". I genvägens Egenskaper, lägger du sedan till -profile ./mappnamn efter sökvägen för "Mål".

    Uppdatering

    Är det något jag måste göra för att fortsätta använda senaste versionen av Instantbird?

    Nej, Instantbird söker periodiskt efter uppdateringar, som standard, och ber om tillåtelse att uppgradera sig självt om en ny version hittas.

    Tycker du inte om det här beteendet, kan du ändra det under Inställningar.

    Om jag vill uppdatera nu då?

    I Instantbirds hjälpmeny finns en menypost som heter Sök efter uppdateringar, som du kan använda för manuella uppdateringskontroller.

    Kan jag installera en nyare version över den befintliga?

    Ja.

    Kommer mina Tillägg att fungera efter en uppgradering?

    Kompatibla tillägg kommer fortfarande att fungera efter en uppgradering. Om ett tillägg inte är kompatibelt med den uppgraderade versionen av Instantbird, kommer programmet att föreslå en sökning efter en uppdaterad tilläggsversion, och i förekommande fall uppdatera tillägget.

    Om ett tillägg inte fungerar efter en uppgradering, kan du kontakta tilläggets utvecklare för att ta reda på om en uppdatering är på gång.

    Avinstallation

    Hur kan jag ta bort Instantbird?

    I Windows kan installerad version avinstalleras från Kontrollpanelen på samma sätt som vilket annat program som helst.

    I andra fall (t.ex portabel version), kan du bara ta bort Instantbird-mappen.

    Normal avinstallation av Instantbird tar inte bort dina konton, chatthistorik, Insticksmoduler eller Tillägg. Dessa data lagras i din profilmapp.

    Återinstallerar du Instantbird efter en avinstallation, kommer all data från profilmappen att återanvändas av den nya installationen.

    Användning

    Kan jag använda flera konton samtidigt?

    Ja, du kan ansluta flera konton samtidigt, med något av de protokoll som stöds.

    Använd Konton (finns under Verktyg i menyn) för att lägga till nya konton.

    Vilka protokoll stöds?

    Standardstödet i Instantbird innefattar: AIM, Bonjour, Facebook Chat, Gadu-Gadu, Google Talk, Groupwise, ICQ, IRC, MSN, MySpaceIM, Netsoul, Odnoklassniki, QQ, Simple, Twitter, VKontakte, XMPP, Yahoo och Yahoo JAPAN.

    Fler protokoll kan installeras som Tillägg.

    När jag försöker ansluta mitt Facebook-konto, får jag felmeddelandet Invalid XMPP ID. Vad är problemet?

    Du har angett e-postadressen du använder på Facebooks hemsida, som användarnamn. Facebook-chatten förväntar sig ett unikt användarnamn i namnfältet. Gå till http://www.facebook.com/username/ för att kontrollera det.

    När jag försöker ansluta mitt Facebook-konto, får jag felmeddelandet Ej autentiserad. Vad är problemet?

    Du måste aktivera XMPP-anslutningar på ditt Facebook-konto.

    1. Besök Facebook-chatt när du är inloggad på ditt Facebook-konto för att aktivera XMPP-anslutning.
    2. Logga ut från Facebook-sidan.
    3. Logga in igen, på Facebook-sidan.
    4. Anslut ditt Facebook-konto i Instantbird ("Verktyg" > "Konton" och tryck "Anslut" på ditt Facebook-konto) så bör det fungera.

    Var kan jag hämta tillägg (och teman)?

    Du kan söka efter tillägg från Hämta tillägg i tilläggshanteraren (finns under Verktyg), och du kan gå till webbsidan för Instantbird's tillägg, bläddra bland tillägg och teman.

    Loggar Instantbird mina konversationer och chattar?

    Ja, Instantbird skapar loggfiler som standard. Använd inställningarna under Integritet (finns i menyn Verktyg/Alternativ), för att konfigurera loggningen som du vill. Vill du ta en titt på själva loggen, kan du använda knappen Visa logg-mapp... i samma fönster.

    Var lagras loggarna?

    Namn och sökväg för loggfilerna är följande: sökväg till profilmappen/logs/protokoll/kontakt- eller chatt-namn/datum och tid.txt (replace the parts in italic by actual values).

    Var finns min profilmapp?

    Den finns på en av följande platser, beroende på operativsystem:

    Windows%appdata%\Instantbird\Profiles\ (kopiera och klistra in detta, i Windows Utforskaren)
    Mac OS X~/Library/Application Support/Instantbird/Profiles/
    Linux (Unix)~/.instantbird/

    Varje version av Instantbird, som installeras efter en avinstallation, kommer att fortsätta använda data från den här profilmappen.

    Kan jag komma åt about:config, för att fintrimma inställningarna?

    Vi rekommenderar det inte, men about:config är åtkomlig i verktygsmenyn, Alternativ/Avancerat.

    Utveckling

    Varför utvecklar ni Instantbird?

    Vi ger er Instantbird för att vi tror att snabbmeddelanden är en viktig del av era online-liv..

    Hur är Instantbird licensierad?

    Instantbird är licensierat under GNU GPL-licens version 2.0 eller senare (eftersom det använder libpurple, som är GPL-licensierat). Dessutom... det mesta av källkoden är också licensierad med Mozilla Public License (MPL), version 2.0.

    Var finns källkoden?

    En 'tarball' med källkoden för varje släppt version är tillgänglig från nedladdningssidan. Den senaste utvecklingskoden kan hämtas från vår 'Mercurial code repository' genom att följa våra kompileringsinstruktioner.

    Vem utvecklar Instantbird?

    Vi är ett litet team med motiverade individer men vi hoppas att många, inklusive dig, vill ansluta till oss för att göra projektet ändå bättre.

    Är projektet sponsrat av Mozilla?

    Mozilla foundation har inte hjälpt oss finansiellt.

    Logotypen "Powered by Mozilla", på vår hemsida, innebär att Instantbird är beroende av kod och teknologier som utvecklas av Mozilla-gemenskapen. Vi är väldigt tacksamma mot Mozilla-gemenskapen i sin helhet, för den fantastiska teknik som Instantbird bygger på.

    Hur kan jag bli involverad?

    Det finns flera sätt att ta del i projektet. Du måste inte vara programmerare för att hjälpa oss. Gå till 'Get involved' för detaljerad information.

    Kan jag hjälpa till att översätta till mitt språk?

    Ja! Gå till 'Translation wiki page' för detaljerad information.

    Hur skapar man add-ons?

    Gå till 'Extensions wiki page' för detaljerad information.

    Fungerar Firefox-/Thunderbird-tillägg i Instantbird?

    Inte utan åtgärd, men de flesta kan anpassas. Gå till 'Porting Firefox extensions page' för mer detaljerad information.

    Hur kan jag följa den aktuella utvecklingen?

    För att hålla dig informerad om viktiga nyheter, kan du följa vår blogg.

    Vill du följa våra diskussioner, är du välkommen in på vår IRC-kanal: #instantbird på irc.mozilla.org.

    'Nightly builds' produceras varje dag, så att folk kan hjälpa oss testa de nya funktioner som just har lagts till. Använd dem gärna, men se upp! De är kanske inte stabila, och om du bestämmer dig för att använda dem, förväntas du göra det för att hjälpa oss testa de senaste funktionerna, inte för att bara vara en 'cool kille' med senaste leksakerna. Så om du hittar några fel... var snäll och rapportera dem istället för att klaga (Filing a bug: Vad en buggrapport bör innehålla).

    Vad kommer nästa version att innehålla?

    Se vår 'roadmap'.

    När kommer nästa stabila version att släppas?

    Vi är väldigt engagerade och liksom du, angelägna om att projektet skall röra sig framåt så fort som möjligt, men med tanke på förutsättningarna för mjukvaruutveckling kan det vara problematiskt att sätta tidsgränser, särskilt som vi hellre prioriterar bibehållen kvalitet.

    Kommer Instantbird att stödja överföring/videosamtal/din favoritfunktion?

    Se vår 'roadmap'.

    Du är välkommen att diskutera funktioner som inte är listade, för att se om intresse finnes eller om det går att implementera som ett tillägg.
