Ladda ner källkod

Eftersom Instantbird är ett open source-projekt, kan du fritt ladda ner och modifiera källkoden.

Vad är nytt?

  • Loggvisaren grupperar nu konversationerna efter datum.
  • Twitter-förbättringar
    • Teckenräknaren för Twitter har förbättrats för att beräkna automatisk länkförkortning, vilket tillåter dig att enkelt twittra länkar utan att fundera på deras längd!
    • Uppdaterat till Twitter API v1.1. Notera att Instantbird 1.3 kan sluta fungera med Twitter den 11:e Juni 2013!
    • Twitter inkluderar nu alla du följer, som deltagare i din tidslinje.
  • IRC-autentiseringen fungerar bättre med utkastare (ex. ZNC).
  • Nu kan du enkelt åsidosätta självsignerade/ogiltiga/utdaterade certifikat för IRC-servrar.
  • Varje konto innehåller nu felsökningsloggar som kan nås genom att högerklicka på kontot i kontohanteraren och välja "Kopiera felsökningslogg", dessa innehåller viktig information för utvecklare, för att diagnostisera användarnas problem. (Notera att felsökningsloggar KAN innehålla känslig information.)
  • Under huven
    • Uppdaterat: Instantbird 1.4 baseras på Mozilla 20.0.1 och använder libpurple 2.10.7!
    • Stödet för Mac OS X < 10.6 upphör! Uppgradera ditt operativsystem eller fortsätt använda Instantbird 1.3.
  • Och mer... läs den fullständiga Ändringsloggen för detaljerad information om kodförändringar sedan Instantbird 1.3.
