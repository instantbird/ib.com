Baixar o código fonte

Instantbird é um projeto open source. Você pode baixar o código fonte e modificá-lo.

O que há de novo?

  • O visualizador de registros mostra as conversas como um visualizador de conversas, graças ao novo formato JSON-based log file que armazena meta-dados junto ao texto da conversa.
  • Foi adicionado o suporte ao Bonjour (é necessário o Serviço de impressão do Bonjour no Windows ou Avahi no Linux).
  • Interface aprimorada para chats multi-usuários:
    • Integração com a tecla tab melhorada. Leia o nosso post no blog para detalhes.
    • Saiba quem está participando na conversa, com a identificação dos participantes por cores.
  • Melhorias no IRC:
    • Canais são reconectados automaticamente após a conexão com o servidor.
    • Instantbird rastreia o status dos contatos do IRC usando os comandos WATCH ou MONITOR, se for suportado.
    • Mensagens de ChanServ messages são mostrados no canal em que fazem referência.
    • Nenhuma mensagem de NickServ te interrompendo depois do logon.
  • Para aprimorar sua segurança, as senhas são armazenadas no gerenciador de senhas do Mozilla. É possível protegê-las, como no Firefox e Thunderbird, usando uma senha mestre.
  • O Assistente de Contas facilita a criação de novas contas por meio de uma lista de protocolos mais populares. Pode-se ter acesso também a todos os outros protocolos.
  • Integração com o ícone de bandeja foi melhorado: você pode mudar o seu status diretamente no menu de contexto do sistema.
  • Encontre rapidamente o último diálgo de conversa: A posição da primeira mensagem não-lida está marcada visualmente (e pode-se rapidamente saltar pressionando Alt-PgUp/PgDn ou passando).
  • Ao restaurar conversas antigas, será mostrada uma barra de progresso ao invés de congelar a interface do usuário.
  • As mensagens já lidas serão distinguidas das não-lidas em todas os estilos de mensagem padrão. Esses estilos também respeitarão as configurações de fonte em "Preferencias->Conteúdo".
  • A navegação de conversa pelo teclado foi aprimorado por permitir deslizamento através de uma caixa de texto de entrada(vazia): Use as setas, Page Up/Down, ou Home/End! Existem novos atalhos para colocar a conversa em espera (ESC) e acessar o visualizador de log (Ctrl+Shift+H, similar ao "Histórico" no Firefox).
  • Melhorias na acessibilidade foram feitas para novas mensagens, contatos e grupos de contatos.
  • Para desenvolvedores de Extensões:
    • Preferências de controles de sons mais precisos: por exemplo Controles Avançado de Sons (Advanced Sound Controls).
    • Reorganização da lista de contatos: por exemplo Organizar por Status (Sorty by Status).
    • É possível adicionar facilmente novos protocolos usando JavaScript: por exemplo Protocolo VZnet (VZnet Chats).
  • Instantbird por dentro
    • Temos as nossas próprias implementações de JavaScript extensíveis para:
      • Chat do Facebook e do Google Talk, baseado em nosso plugin do protocolo XMPP (do Google Summer of Code 2011).
      • IRC
    • Atualizado: Instantbird 1.2 é baseado em Mozilla 14.0.1 que trazem novas possibilidades para desenvolvedores de extensão e usa libpurple 2.10.4.
    • The license of most of the code was updated to the Mozilla Public License (MPL) 2.0, official builds of Instantbird 1.2 are distributed under the GNU Public License 2.0 ou superior.
    • Estamos usando libqq-pidgin para QQ porque o protocolo QQ não estar mais incluído no libpurple.
    • Mudanças de platforma fizeram com que perdessemos o suporte para Windows 2000 e do Windows XP inferior ao Service Pack 2. Recomendamos a atualização para o Windows XP SP2 ou superior.
  • E mais... leia a nossa Log de mudanças completa para detalhes das 403 mudanças de código desde o Instantbird 1.1.

Problemas conhecidos

  • Falhas na reconexão SSL no freenode (bug 1100).
  • certificado autoassinado ou manuseio de certificado inválido (bug 1292).
