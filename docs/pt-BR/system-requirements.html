Requisitos do Sistema

Os seguintes requisitos são necessários para executar Instantbird.

Windows

  • Sistemas Operacionais: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128Mb de RAM
  • 50Mb de espaço no Disco Rígido

Mac

  • Sistemas Operacionais: Mac OS X 10.6 (Snow Leopard) ou superior
  • 256Mb de RAM
  • 100Mb de espaço no Disco Rígido

Linux

Instantbird precisa destas bibliotecas (libraries) para ser executado no Linux:

  • GTK+ 2.18 ou superior
  • GLib 2.22 ou superior
  • Pango 1.14 ou superior
  • X.Org 1.0 ou superior
  • libstdc++ 4.3 ou superior

Algumas distribuições Linux podem prover pacotes que possuam requisitos diferentes.
