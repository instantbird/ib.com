Baixar o código fonte

Instantbird é um projeto open source. Você pode baixar o código fonte e modificá-lo.

Novidades

  • Criar uma nova aba de conversa ficou mais fácil.
    • Ao clicar no botão '+' numa janela de conversa, será mostrado uma lista de conversas que pode ser iniciado com um simples clique.
    • A lista é sorteada com um algoritmo de frequência, exibindo os contatos pela ordem em que você conversa com frequência.
    • Essa lista inclui também os canais de aviso dos serviddores IRC dos quais você está conectado.
  • Novas ferramentas que melhor se adapte ao estilo de Instantbird
  • Interface de chat multi-usuário melhorada:
    • É possível iniciar um chat privado ou adicionar participantes de uma sala de chat através do menu de contexto.
    • Contatos destacados nas salas de chat tem agora ferramentas e menus de contexto.
  • As salas de chat que forem unidas automaticamente ficarão no espaço das Conversas em Espera, mesmo que você reinicie Instantbird.
  • Uma lista de nicks alternativos para IRC pode ser configurado, no caso de você preferir, seu nickname favorito será exibido quando se conectar.
  • Páginas about: (ex.: about:config) podem ser executadas facilmente, pelo comando /about (ex.: /about config).
  • Suporte à tecnologia Retina display no Mac OS X.
  • Contatos do Google Talk e usuários do app Hangouts para Android são mostrados, no status, como "pelo celular".
  • Usuários do Google Hangouts não serão mais exibidos como se estiveessem sempre digitação.
  • Melhor suporte para a exibição de idiomas RTL (que são escritos da direita para a esquerda, como o arábe, hebraico, etc.) nas conversas.
  • O protocolo vKontakte foi removido porque o suporte da rede social ao cliente XMPP foi desativado.
  • New for developers: Novo API para adicionar painéis de abas com conteúdo arbitrário para janelas de conversas: Documentação in-code.
  • Atualizado para Mozilla 25.
  • Varios pequenos bugs e crashers foram resolvidos.
  • E muito mais... leia toda a ChangeLog (em inglês) para mais detalhes sobre as mudanças de código de Instantbird 1.4 para a versão atual.

Erros conhecidos:

  • Usuários NVDA deverão atualizar para a versão 2014.1 para trabalhar com bugs na plataforma da Mozilla que leva para "Unknown" being said when scrolling through the contact list.
  • Ao clicar em URLs em algumas distribuições Linux mais novas, para resolver essa falha, execute o comando /about config numa janela de conversa e procure pela registro network.protocol-handler.warn-external, e mude o valor para true (verdadeiro). Voce será avisado para selecionar um aplicativo após clicar nesses links. Veja o bug 1995.
