Baixar o código fonte

Instantbird é um projeto open source. Você pode baixar o código fonte e modificá-lo.

Novidades?

  • Grandes melhorias de acessibilidade.
  • Melhorias no protocolo IRC
    • Mensagens longas serão enviadas em várias partes ao invés de serem cortadas
    • Autenticação SASL passa a ser suportada, necessário para certas faixas de IP ou quando usar Tor e conectar-se para Freenode.
  • Melhorias no protocolo Twitter
    • Sua descrição pessoal passa a ser mostrada (e pode ser editada) acima da linha do tempo.
    • Responder um tweet agora responde para todos os usuários, como no site do Twitter!
    • O ícone guia para a linha de tempo do Twitter é agora o Twitter bird para diferenciar explicitamente a linha de tempo e a janela de chat.
  • A extensão "Show Nick" foi incorporado ao Instantbird. Isso destaca quando apelido de um usuário é mencionado em um bate-papo para ver facilmente as conversas que estão acontecendo. Esperamos que aproveite essa melhoria, mas é possível desabilitá-lo indo em "Preferências", clique no botão "Avançado", depois "Editor de Configurações", digite "messenger.conversations.showNicks", e mude o valor para "false".
  • Dois novos protocolos foram adicionados via XMPP: Odnoklassniki e VKontakte.
  • Por dentro de Instantbird
    • Atualização: Instantbird 1.3 é baseado no Mozilla 16.0.2 que traz grande novas possibilidades para desenvolvedores de extensões e usa libpurple 2.10.4. Esta versão é a última que é suportado no Mac OS 10.5 e PPC, uma vez que estas não será possível o suporte com Mozilla 17.
    • A memória consumida por libpurple e das suas dependências é rastreada em about:memory.
  • E mais... leia a lista completa de ChangeLog para mais detalhes das 136 mudanças de código desde Instantbird 1.2.
