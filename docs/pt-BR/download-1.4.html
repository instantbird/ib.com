Baixar o código fonte

Instantbird é um projeto open source. Você pode baixar o código fonte e modificá-lo.

Novidades

  • Agora o visualizador do histórico organiza suas conversas pela data.
  • Melhorias no Twitter
    • O contador de caracteres para o Twitter foi melhorado para encurtar os links inseridos no tweet, permitindo inserir links facilmente sem aborrecimentos com o seu tamanho!
    • O API do Twitter foi atualizado para a versão 1.1 . Fique atento: A versão do API do Instantbird 1.3 pode deixar de funcionar a partir de 11 de Junho de 2013!
    • Agora o protocolo do Twitter inclui todos os usuários que você segue como um participante na sua linha de tempo.
  • A autenticação do IRC foi melhorada para funcionar melhor com bouncers (segurança)(ex.: ZNC).
  • Você pode facilmente substituir certificados autoassinados/inválidos/desatualizados para servidores IRC.
  • Cada conta de usuário possui histórico de depuração que podem ser acessados ao clicar com o botão direito do mouse em qualquer protocolo na janela Contas e clicando em "Copiar Debug Logs", onde estão as informações essenciais para os desenvolvedores diagnosticarem falhas. (Observe que os históricos de diagnóstico PODEM conter informações confidenciais.)
  • Por dentro de Instantbird
    • Atualização: Instantbird 1.4 é baseado no Mozilla 20.0.1 e usa libpurple 2.10.7!
    • Instantbird não suporta Mac OS X inferior a versão 10.6 (Snow Leopard), portanto incentivamos uma atualização de seu Sistema Operacional ou continue usando Instantbird 1.3.
  • E mais: leia a nossa lista completa de modificaçõs em nosso ChangeLog de Instantbird 1.3.
