    • Instalando

    Preciso fornecer novas informações de contato para meus amigos?

    Não, com Instantbird você pode usar as suas contas de mensageitos existentes em um único aplicativo. Se você já possui algum mensageiro instalado em seu computador, não precisa criar uma nova conta para usar no Instantbird.

    Será que Instantbird funciona no meu computador?

    Instantbird é suportado atualmente no Windows XP SP2 ou superior, no Mac OS X 10.5 ou superior, e em distribuições Linux. Leia os requiositos do sistema para mais informações.

    Como eu baixo a versão mais recente de Instantbird?

    Na página inicial do site será mostrado um link para baixar a versão e o idioma disponível para você. Caso queira escolher baixar Instantbird em outros idiomas e sistemas operacionais, clique em _ logo abaixo da opção principal.

    Posso instalar Instantbird sem permissão de administrador do meu computador?

    Com certeza!

    Posso instalar Instantbird e manter meu outros mensaheiros instantâneos no meu computador?

    Sim! Instantbird pode coexistr com outros mensageiros no mesmo computador sem problemas.

    Como instalar Instantbird no Windows?

    Existe um instalador de Instantbird para Windows. Você deve executar o arquivo que baixou do site, e siga as instruções do instalador.

    Como instalar Instantbird no Mac OS X?

    Dê um clique duplo no Instantbird disk image (um arquivo com o final".dmg") que você baixou. Mova o ícone do Instantbird para a pasta Aplicativos.

    Como instalar Instantbird no Linux?

    Extraia o conteúdo do arquivo baixado, e execute o arquivo chamado instantbird. Se uma caixa de diálogo perguntá-lo se deseja editar ou executar o arquivo, selecione "Executar".

    Nós disponibilizamos Instantbird somente na arquitetura de 32-bits. Caso queira executálo em um Sistema Operacinal de 64-bits, você terá que instalar as bibliotecas de compatibilidade disponibilizados pela sua distribuição. Por exemplo, no Ubuntu, instale o pacote ia32-libs por digitar no terminal sudo apt-get install ia32-libs .

    Existe alguma versão portável de Instantbird (que possa ser usado em um dispositivo USB)?

    Se desejar usar Instantbird em um dispositivo USB, ele irá armazenar seu perfil de usuário no disco rígido, por padrão.

    Você pode fazer que Instantbird armazene seu perfil de usuário em um dispositivo USB usando o argumento de linha de comando -profile.

    Para isso, clique com o botão direito do mouse no arquivo instantbird.exe e clique em "Criar Atalho". Nas propriedades do atalho, edite e insira o parâmetro -profile ./foldername.

    Atualização

    Existe algo que preciso fazer para continar usando a última versão de Instantbird?

    Não. Por padrão, Instantbird pesquisará por atualizações e pedirá sua permissão para atualizar você mesmo se encontrar uma nova versão.

    Se não gostar desse comportamento, você pode modificá-lo em preferências.

    O que faço se desejo atualizar Instantbird agora?

    Clique em Buscar atualizações, dentro do menu Ajuda. Quando existir uma atualização, ela aparecerá na janela. Basta clicar no link exibido e seguir as instruções.

    Posso instalar uma nova versão com uma já instalada?

    Sim.

    Minhas extensões funcionarão depois de uma atualização?

    Extensões compatíveis funcionarão depois de uma atualização. Com as extensões não compatíveis, Instantbird irá conferir se existe uma versão compatível para esta versão para atualzação.

    Se sua extensão não funcionar depois da atualização, você pode contatar o seu autor para encontrar uma versão em desenvolvimento.

    Desinstalando

    Como desinstalo Instantbird?

    Se você usou um instalador para Windows, basta executar o desinstalador que está no Painel de Controle.

    Nos outros casos, você deve excluir a pasta onde está Instantbird.

    Quando você remove Instantbird, suas contas de usuários, históricos de conversas e extensões estão armazenados na sua pasta de perfil.

    Qualquer versão de Instantbird, que você possa instalar depois, irá utilizar os dados presentes nessa pasta.

    Utilizando

    Posso utilizar diversas contas ao mesmo tempo?

    Sim, você pode usar diversas contas dos protocolos suportados ao mesmo tempo.

    Utilize o Gerenciador de Contas, no menu Ferramentas, para adicionar uma outra conta.

    Quais protocolos são suportados?

    Instantbird suporta estes protocolos: AIM, Bonjour, Facebook Chat, Gadu-Gadu, Google Talk, Groupwise, ICQ, IRC, MSN, MySpaceIM, Netsoul, Odnoklassniki, QQ, Simple, Twitter, VKontakte, XMPP, Yahoo e Yahoo JAPAN.

    Protocolos Adicionais podem ser instalados por extensões.

    Quando tento conectar minha conta do Facebook, aparece uma mensagem de erro Invalid XMPP ID. Qual é o problema?

    Você inseriu no nome do usuário dessa conta o email que utiliza para entrar no Facebook. O que você deve inserir no nome do usuário do Facebook é o seu nome de usuário único. Visite http://www.facebook.com/username/ para mais informações.

    Quando tento conectar minha conta do Facebook, aparece uma mensagem de erro Não Autorizado. Qual é o problema?

    Você precisa habilitar, no Facebook, as conexões XMPP.

    1. Acesse o Chat do Facebook enquanto estiver logado em sua conta, e habilite o acesso ao protocolo XMPP.
    2. Desconecte-se do Facebook.
    3. E reconecte-se ao Facebook.
    4. Conecte sua conta do Facebook no Instantbird ("Ferramentas" > "Contas" e clique no botão "Conectar" em sua conta do Facebook).

    Onde obtenho extensõoes (e temas) para Instantbird?

    Você pode buscar extensões na aba Adicionar no gerenciador de extensões (clicando no menu Ferramentas) serão mostrados algumas extensões rewcomendadas. Caso queira mais extensções, você pode visitar o site de extensões para Instantbird (Instantbird's add-on) onde irá pesquisar por extensões experimentais e revisões.

    Instantbird cria logs das minhas conversas e chats?

    SIm, Instantbird cria logs por padrão. Use as configurações do painel Privacidade pane no diálogo Opções/Preferências para configurá-lo do jeito que quiser. Se deseja ter acesso aos logs, clique no botão Mostrar pasta de registro....

    Onde estão armazenados os logs?

    O nome e endereço dos logs estão: pasta de usuário/logs/protocol/buddy ou chat name/date and time.txt (mude as partes em itálico pelos valores atuais).

    Onde está minha pasta de usuário?

    Está localizado nesses locais, dependendo do seu sistema operacional:

    Windows%appdata%\Instantbird\Profiles\ (copie e cole isso exatamente no Windows explorer)
    Mac OS X~/Library/Application Support/Instantbird/Profiles/
    Linux (Unix)~/.instantbird/

    Qualquer versão de Instantbird que instalar, após remover uma versão anterior, continuará usando os dados desta pasta de usuário.

    Como acesso about:config para ajustar algumas preferências?

    Apesar de desencorajarmos a usá-lo, about:config pode ser acessado clicando em Ferramentas, Preferências, em seguida, clique na aba Avançado e, por fim, no botão Editor de configurações.

    Desenvolvimento

    Por que vocês fazem Instantbird?

    Produzimos Instantbird porque nós acreditamos que mensageiros instantâneos torna-se fundamental na sua vida digital.

    Como é licenciado Instantbird?

    Instantbird está licenciado sob os termos da licença GNU GPL version 2.0 ou superior (porque usamos libpurple, que está sob a licença GPL). No entanto, grande parte do código fonte está licenciado sob a licença tripla Mozilla (MPL 1.1/GPL 2.0/LGPL 2.1).

    Onde está o código fonte?

    O pacote tarball com o código fonte de cada versão disponível está disponível em Outros Sistemas e Idiomas. O último código de desenvolvimento pode ser obtido no nosso repositório de códigos do Mercurial e seguir as instruções de construção.

    Quem fez Instantbird?

    Somos um pequeno time de indivíduos altamente motivados, mas esperamos uma ajuda de muitas pessoas - inclusive a sua - para fazer este projeto cada vez melhor.

    Mozilla está financiando o projeto?

    A fundação Mozilla não nos ajuda financeiramente.

    A logo "Powered by Mozilla" que está em nossa página inicial representa que Instantbird utiliza códigos e tecnologias desenvolvidas pela comunidade Mozilla. Somos muito gratos à comunidade Mozilla como um todo pela incrível tecnologia na qual which Instantbird é baseado.

    Como posso fazer parte?

    Existem diversas maneiras de fazer parte deste projeto. Não é exigido conhecimento de programação para nos ajudar. Veja mais detalhes na seção Faça Parte.

    Posso ajudar na tradução de Instantbird para o meu idioma?

    Sim! Veja como fazer isso na seção de tradução em nossa página Wiki(em inglês).

    Como posso criar extensões?

    Veja detalhes na seção de extensões em nossa página Wiki.

    As extensões de Firefox/Thunderbird podem funcionar no Instantbird?

    Não diretamente, mas elas podem ser adaptadas (portadas). Veja detalhes na seção "porting Firefox".

    Como posso seguir processo de desenvolvimento atual?

    Para estar informado das novidades, você provavelmente pode seguir nosso blog.

    Se desejar acompanhar nossas discussões, sinta-se bem-vindo para se juntar ao nosso canal no IRC: #instantbird em irc.mozilla.org server.

    Nightly builds são produzidos diaraimente, portanto todos são bem-vindos para nos ajudar a testar os recursos adicionados. Sinta-se a vontade para usá-los, mas fique atento! Eles ainda não estão estáveis, e se decidir usá-lo, espera-se que faça isso para nos ajudar a testar os recursos do aplicativo, ao invés de "brincar com o brinquedo novo". Caso encontre algum bug, por favor, relate-o (Arquive um bug: Com o que um relatório de bug deve conter) em vez de ficar resmungando.

    O que se deve esperar na próxima versão de Instantbird?

    Veja detalhes em roadmap.

    Quando será lançado uma versão mais recente?

    Estamos muito empolgados com este projeto e gratos com o seu interersse de avançarmos o mais rápido possível. No entanto, devido à natureza de desenvolvimento de software, é um desafio divulgar datas de lançamentos. Focamos na qualidade en vez da quantidade.
