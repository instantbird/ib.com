Den Quellcode herunterladen

Da Instantbird ein Open-Source-Projekt ist, darf der Quellcode gerne heruntergeladen und bearbeitet werden.

Was gibt es neues?

  • Umgestaltetes Kontaktlisten-Fenster:
    • Zusammenführen von Kontakten: Falls Sie mit der selben Person über verschiedene Instant-Messaging-Netzwerken in Kontakt stehen, können Sie nun die Benutzernamen dieser Person von allen IM-Diensten zu einem einzigen Kontakt verschmelzen. Wenn ein neuer Chat geöffnet wird, wird automatisch das Netzwerk gewählt in dem Ihr Gegenüber gerade online ist und das Gesprächsfenster wird automatisch die Verbindung umschalten, falls zu einem anderen Dienst gewechselt wird.
    • Schlagwörter: Schlagwörter ersetzen die Gruppen in der Kontaktliste, jeder Kontakt lässt sich einem oder mehreren Schlagwörtern zuordnen. Einzelne Schlagwörter lassen sich durch einen Klick auf das »x« an der rechten Seite verbergen. Alle Kontakte die online sind, aber zu keinem sichtbaren Schlagwort gehören werden in dem Schlagwort »Weitere Kontakte« am Ende der Liste zugeordnet.
    • Das Konktaklisten-Fenster kann nun …
      • auf dem Mac geschlossen werden ohne Instantbird zu beenden; es kann vom Dock wieder geöffnet werden.
      • in Windows und Linux in den Infobereich minimiert werden. Als Standard wird die Kontaktliste beim Schließen in den Infobereich minimier, dies kann jedoch über die Einstellungen verändert werden.
    • Benutzer können nun ein Avatar-Bild und den Anzeigenamen ihrer Konten direkt im Kontaktlisten-Fenster ändern.
    • Die Kontaktliste ist sortiert. Sowohl Schlagwörter, als auch Kontakte erscheinen nun alphabetisch sortiert.
    • Hübschere Animationen.
  • Twitter-Unterstützung: Wenn ein Twitter-Konto verbunden wird, erscheint automatisch die Timeline. Wenn das Fenster bzw. der Tab geschlossen wird, öffnet sie sich automatisch, wenn ein neuer Tweet eintrifft. Der Benutzer sollte die Verbindung im Konten-Menü trennen um keine weiteren Nachrichten zu empfangen.
    Es gibt eine „Folgen“-Funktion, die es ermöglicht einzelne Schlagwörter in die Timeline aufzunehmen. Dies ist eine kommaseparierte Liste, Komma heißt ODER, Leerzeichen heißt UND.
  • Eine neue Info-Toolbar oben an dem Gesprächsfenster, die den Kontakt-Status, den Avatar, den Anzeigennamen anzeigt. Zusätzlich kann der verwendete IM-Dienst durch einen Klick auf das Protokoll-Icon geändert werden.
  • Das Aussehen der Tabs wurde aktualisiert um Firefox 4 zu gleichen, und Benutzer von aktuellen Windows-Versionen werden einige Aero-Glass-Effekte zu schätzen wissen.
  • Bubbles, das Standard-Theme, hat einige zeitbezogene Funktionen hinzubekommen, siehe unseren Blog-Beitrag für weitere Details.
  • (nur Windows 7) Unterstützung von Jump List um schnell den Status zu wechseln.
  • Unter der Haube: Protokoll-Plugins können nun in JavaScript implementiert werden.
  • Viele kleine Verbesserungen, darunter:
    • Man kann nun schnell zu dem x-tem Tab zu springen, über <Modifier>+<x> im Gesprächsfentster, wobei <Modifier> Strg bei Windows/Linux und Command auf Mac ist.
    • Ein Hilfe-Befehl ('/help') wurde hinzugefügt, so dass man nun schnell und einfach die Befehle sehen kann, die in der aktuellen Konversation zur Verfügung stehen.
    • Ein unbekannter Status wird nun vom Offline-Status durch verschiedene Icons unterschieden.
    • Eine dunkle Variante des "Simple"-Themes.
  • Aufgefrischt: Instantbird 1.0 basiert nun auf libpurple 2.7.11 und Mozilla 2.0.1, die tolle neue Möglichkeiten für Add-on-Entwickler bietet (z.B. neustartlose Add-ons).
  • Verbesserte Stabilität: Wir haben die Absturzmeldungen die wir von den Veröffentlichungen der Versionen 0.2 und 0.3, sowie den Nightly-Builds ausgewertet, um Bugs zu beheben, die zu Abstürzen führten.
  • Und viel mehr … lesen Sie das komplette ChangeLog für die Details zu den 329 Code-Änderungen seit Instantbird 0.2.

Bekannte Probleme

  • Nach dem Schließen der Twitter-Timeline kann sie nicht mehr manuell geöffnet werden, um einen Tweet zu senden. Die Timeline öffnet sich jedoch automatisch wieder, wenn einen neue Nachricht eintrifft.
