    • Installation

    Muss ich meinen Freunden/ neue Kontakt-Informationen mitteilen?

    Nein, mit Instantbird können Sie alle bestehenden Instant-Messaging-Konten mit einem einzigen Programm verwenden. Wenn Sie bereits Instant-Messaging verwenden, müssen sie keine neuen Konten einrichten um Instantbird benutzen zu können.

    Wird Instantbird auf meinem Rechner laufen?

    Instantbird unterstützt zur Zeit Windows XP SP2 oder neuer, Mac OS X 10.5 oder neuer und Linux. Auf der Seite Systemvoraussetzungen finden Sie weitere Details.

    Was sollte ich herunterladen um die neuste Version von Instantbird zu erhalten?

    Der Download-Link auf der Startseite gibt automatisch die Version von Instantbird an, die für Ihr System am besten geeignet scheint. Falls Sie selbst das Betriebssystem und die Sprache auswählen wollen gehen Sie bitte auf Download-Seite.

    Kann ich Instantbird ohne Administrator-Rechte installieren?

    Ja!

    Kann ich Instantbird installieren und meinen vorigen Instant-Messaging-Client auf dem Rechner behalten?

    Natürlich! Instantbird und andere IM-Clients können parallel auf einem Rechner betrieben werden ohne Probleme zu verursachen.

    Wie installiere ich Instantbird auf Windows?

    Instantbird wird für Windows in einem Installationspaket angeboten. Einfach die heruntergeladene Datei ausführen und sich durch die Installationsroutine führen lassen.

    Wie installiere ich Instantbird auf Mac OS X?

    Doppelklick auf die heruntergeladene Diskimage-Datei von Instantbird (eine Datei mit der Endung „.dmg“). Danach das Instantbird-Icon zu dem Programm-Ordner ziehen.

    Wie installiere ich Instantbird auf Linux?

    Extract the content of the downloaded archive, and launch the file named "instantbird". If a popup dialog asks you if you want to edit or launch the file, select "launch".

    We currently only provide 32-bit builds. In order to run these on a 64-bit system, you will have to install the 32-bit compatibility libraries provided by your distribution. For example, on Ubuntu, install the package ia32-libs by running sudo apt-get install ia32-libs from the command line.

    Ist Instantbird portabel (also von einem USB-Stick ausführbar)?

    Wenn Instantbird von einem USB-Stick ausgeführt wird, wird das Profil standardmäßig auf der Festplatte gespeichert.

    Instantbird kann ein auf dem USB-Stick gespeichertes Profil zugewiesen werden, in dem man ihn mit dem Parameter -profile startet.

    Dazu einen Rechtsklick auf die Datei instantbird.exe und „Verknüpfung erstellen“ auswählen. Dann bei den Eigenschaften dieser Verknüpfung das Ziel bearbeiten und -profile ./Name-des-Profilorders anhängen.

    Aktualisieren

    Muss ich irgendetwas tun, um immer die neuste Version von Instantbird zu verwenden?

    Nein, standardmäßig prüft Instantbird regelmäßig auf Aktualisierungen, und wird eine Bestätigung für die Aktualisierung fordern, falls eine neue Version gefunden wurde.

    Dieses Verhalten kann in den Einstellungen verändert werden.

    Was wenn ich jetzt updaten möchte?

    Es gibt im Menü den Punkt Nach Updates suchen (über das Hilfe-Menü aufrufbar) damit man nicht auf die Aufforderung zur Aktualisierung warten muss.

    Kann ich über eine bestehende Version drüber installieren?

    Ja.

    Werden meine Add-ons nach einem Update weiter funktionieren?

    Kompatibele Add-ons werden nach einem Update weiter arbeiten. Wenn ein Add-on nicht mehr kompatibel ist, wird Instantbird eine Überprüfung nach einer neueren Version und gegebenfalls ein Update des Add-ons vorschlagen.

    Fall das Add-on nach einen Update nicht mehr funktioniert, können Sie den Autor des Add-ons kontaktieren um herauszufinden, ob eine aktualisierte Version geplant ist.

    Deinstallation

    Wie kann ich Instanbird entfernen?

    Mit Windows, falls der Installer verwendet wurde, kann Instantbird über die Systemsteuerung deinstalliert werden, wie jedes andere Programm auch.

    Ansonsten reicht es, die Instantbird-Ordner zu entfernen.

    Die Deinstallation von Instantbird wird weder die Verbindungen, den gespeicherten Verlauf, noch die Add-ons löschen. Diese Daten befinden sich im Profilordner.

    Jede Instantbird-Version die nach dem Entfernen von Instantbird installiert wird wird die Daten dieses Ordner verwenden.

    Anwendung

    Kann ich mehrere Konten auf einmal verwenden?C

    Ja, es können mehrere Konten von beliebigen unterstützten Protokollen auf einmal verbunden sein.

    Über die Kontenverwaltung (erreichbar über des Menü Extras) können weitere Konten hinzugefügt werden.

    Welche Protokolle werden unterstützt?

    Currently Instantbird supports by default: AIM, Bonjour, Facebook Chat, Gadu-Gadu, Google Talk, Groupwise, ICQ, IRC, MSN, MySpaceIM, Netsoul, Odnoklassniki, QQ, Simple, Twitter, VKontakte, XMPP, Yahoo and Yahoo JAPAN.

    Zusätzliche Protokoll-Plugins können als Add-ons installiert werden.

    Beim Versuch ein Facebook-Konto zu verbinden erscheint der Fehler Invalid XMPP ID. Was ist das Problem?

    Es wurde wahrscheinlich die E-Mail-Adresse, die auch zum Einloggen auf der Facebook-Webseite dient, als Benutzername verwendet. Facebook-Chat erfordert jedoch die Eingabe des speziellen Benutzernamen in diesem Feld. Der Benutzername kann unter folgendem Link angezeigt werden: http://www.facebook.com/username/

    Beim Versuch ein Facebook-Konto zu verbinden erscheint der Fehler Not Authorized. Was ist das Problem?

    You need to enable XMPP connections to your Facebook account.

    1. Visit Facebook Chat while logged into your Facebook account to enable XMPP access.
    2. Log out of the Facebook website.
    3. Log back into the Facebook website.
    4. Connect your Facebook account in Instantbird ("Tools" > "Accounts" and hit the "Connect" button on your Facebook account) and it should complete successfully.

    Where can I get add-ons (extensions and themes)?

    You can search for add-ons from the Get Addons tab of the Addons manager (accessible from the Tools menu) where you will see some recommended add-ons. For more, you can go to Instantbird's add-on website where you can also browses experimental add-ons and post reviews.

    Is Instantbird creating logs of my conversations and chats?

    Yes, Instantbird is creating log files by default. Use the settings on the Privacy pane in the Options dialog to configure it to your liking. If you like to have a look at the files themselves, use the Show log folder... button on the same pane.

    Where are the logs stored?

    The name and path of the log files are as follows: path to profile/logs/protocol/buddy or chat name/date and time.txt (replace the parts in italic by actual values).

    Where is my profile folder?

    It is located in one of the following locations depending on your operating system:

    Windows%appdata%\Instantbird\Profiles\ (copy and paste this exactly in the Windows explorer)
    Mac OS X~/Library/Application Support/Instantbird/Profiles/
    Linux (Unix)~/.instantbird/

    Any version of Instantbird that you install after removing Instantbird will continue to use the data from this profile folder.

    Can I access about:config to fine tune some preferences?

    While we discourage using it, about:config is accessible from the Advanced tab of the preferences dialog.

    A tarball of the source code of each released version is available from the Download-Seite. The latest development code can be obtained from our Mercurial code repository by following the build instructions.
