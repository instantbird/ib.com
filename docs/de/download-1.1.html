Den Quellcode herunterladen

Da Instantbird ein Open-Source-Projekt ist, darf der Quellcode gerne heruntergeladen und bearbeitet werden.

Was gibt es neues?

  • Gespräche können nun geparkt werden:.
    • Ein Gespräch kann nun aus dem Kontextmenü heraus geparkt werden. Geparkte Gespräche werden oben im Kontaktlisten-Fenster angezeigt, wo sie einfach per Doppelklick wieder geöffnet werden können.
    • Das Schließen von Gesprächs-Tabs führt nun nicht mehr zu verpassten Nachrichten: Wenn man ein Fenster mit ungelesenen Nachrichten schließt, wird das Gespräch automatisch geparkt anstatt geschlossen.
    • Das Schließen von Chat-Fenstern fügt den Chatraum zu den geparkten Gesprächen hinzu, anstatt ihn zu verlassen.
    • Wenn eine neuen Nachricht in einem geparkten Gespräch ankommt, wird es automatisch wieder geöffnet (Bei Chat-Räumen geschieht dies nur, wenn Ihr Alias erwähnt wird).
    • Die Anzahl der ungelesenen Nachrichten für jedes geparktes Gespräch wird deutlich angezeigt. Das wird sich besonders in IRC-Chat-Räumen als nützlich erweisen, wenn man gerade nicht aktiv ist!.
  • Verbessertes Infobereichssymbol für Linux/Windows:
    • Das Kontakt-Fenster lässt sich nun unter Linux mit einem einzigen Klick wiederherstellen.
    • Das Instantbird-Symbol ist nun auch sichtbar, wenn die Anwendung nicht minimiert ist.
  • Verbesserte Twitter-Umsetzung:
    • Twitter-Objekte (@Erwähnungen, #Hashtags and verkürzte Links) werden nun unterstützt.
    • Nachrichten können nun bequem beantwortet und retweetet werden (über das Kontext-Menü).
    • Twitter-Accounts kann man nun direkt aus dem Kontext-Menü der Tweets folgen und entfolgen.
  • Auf vielfachen Wunsch wird nun IBM Lotus Sametime unterstützt.
  • Infos über Chat-Teilnehmer in Tooltips
    • Die „Whois“-Informationen für IRC werden abgerufen und als Tooltip automatisch angezeigt.
  • Tab-Vervollständigung für IRC-Alias, Twitter-Accounts und Befehle.
  • Die neue Interruptions-Manager-API erlaubt Add-on-Entwicklern einfach neue Add-ons zu schreiben, die Störungen reduzieren können:
    • Events können nach verschiedenen Details (Type, Source, …) gefiltert werden, so kann genau eingestellt werden, welche Aktionen zulässig sind.
  • Die Standard-ICQ-Einstellungen wurden an die neuen Server angepasst.
  • Unbekannte Befehle werden nicht mehr an IRC/XMPP-Chaträume gesendet.
  • Aufgefrischt: Instantbird 1.1 basiert nun auf libpurple 2.10.0 und Mozilla 7.0.1. Das bietet viele neue Möglichkeiten für Add-on-Entwickler..
  • Verbesserte Stabilität: Die Crash-Reports von der 1.0-Veröffentlichtung und den Nightlys wurden ausgewertet und es wurden Bugs behoben die regelmäßig zu Abstürzen geführt haben.
  • Und mehr… Lesen Sie das komplette ChangeLog für Details zu den 138-Code-Änderungen seit Instantbird 1.0.
