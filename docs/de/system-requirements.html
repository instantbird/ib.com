Systemvoraussetzungen

Dies sind die minimalen Systemvoraussetzungen für Instantbird.

Windows

  • Betriebssystem: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128MB RAM
  • 50MB freien Festplattenspeicher

Mac

  • Betriebssystem: Mac OS X 10.6 (Snow Leopard) und neuer
  • 256MB RAM
  • 100MB freien Festplattenspeicher

Linux

Instantbird benötigt folgende Programmbibliotheken um auf Linux zu laufen:

  • GTK+ 2.18 oder höher
  • GLib 2.22 oder höher
  • Pango 1.14 oder höher
  • X.Org 1.0 oder höher
  • libstdc++ 4.3 oder höher

Bitte beachten Sie, dass Linux-Distributoren Pakete mit abweichenden Voraussetzungen anbieten können.
