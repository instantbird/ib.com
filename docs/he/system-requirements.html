System Requirements

The following are the minimum system requirements needed to run Instantbird.

Windows

  • Operating Systems: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128MB of RAM
  • 50MB of hard disk space

Mac

  • Operating Systems: Mac OS X 10.6 (Snow Leopard) and later
  • 256MB of RAM
  • 100MB of hard disk space

Linux

Instantbird needs at least the following libraries to run on Linux:

  • GTK+ 2.18 or higher
  • GLib 2.22 or higher
  • Pango 1.14 or higher
  • X.Org 1.0 or higher
  • libstdc++ 4.3 or higher

Please note that Linux distributors may provide packages for your distribution which have different requirements.
