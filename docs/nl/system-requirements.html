Systeemvereisten

Hier volgen de minimale systeemvereisten voor het uitvoeren van Instantbird.

Windows

  • Besturingssystemen: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128MB RAM
  • 50MB hardeschijfruimte

Mac

  • Besturingssystemen: Mac OS X 10.6 (Snow Leopard) en hoger
  • 256MB RAM
  • 100MB hardeschijfruimte

Linux

Instantbird heeft minstens de volgende bibliotheken nodig om onder linux te werken:

  • GTK+ 2.18 of hoger
  • GLib 2.22 of hoger
  • Pango 1.14 of hoger
  • X.Org 1.0 of hoger
  • libstdc++ 4.3 of hoger

Houd er rekening mee dat Linux-distributeurs pakketten voor uw distributie kunnen leveren die andere systeemvereisten hebben.
