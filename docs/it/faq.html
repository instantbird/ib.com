    • Installazione

    Devo inviare nuove informazioni di contatto ai miei amici?

    No, con Instantbird puoi usare tutti i tuoi account di messaggistica esistenti in una sola applicazione. Se usi già la messaggistica istantanea, non hai bisogno di creare un nuovo account per iniziare ad usare Instantbird.

    Instantbird funzionerà sul mio computer?

    Instantbird attualmente supporta Windows XP SP2 o successivi, Mac OS X 10.5 o successivi, e Linux. Leggi la pagine dei requisiti di sistema per maggiori dettagli.

    Cosa devo scaricare per ottenere l'ultima versione di Instantbird?

    Un collegamento sulla homepage selezionerà automaticamente la versione di Instantbird più adatta al tuo sistema. Se vuoi selezionare manualmente il sistema operativo e la lingua, vai alla pagina di download.

    Posso installare Instantbird senza essere amministratore del mio computer?

    Assolutamente si!

    Posso installare Instantbird e mantenere sul computer miei precedenti client di messaggistica?

    Assolutamente si! Instantbird ed gli altri client possono convivere sullo stesso computer senza causare nessun problema.

    Come posso installare Instantbird su Windows?

    Instantbird è rilasciato per Windows come un eseguibile auto installante. Semplicemente lancia il file che hai scaricato e lasciati guidare dal processo di installazione.

    Come posso installare Instantbird su Mac OS X?

    Fai doppio click sull'immagine disco di Instantbird (un file che finisce per ".dmg") che hai scaricato. Poi trascina l'icona di Instantbird nella cartella Applicazioni.

    Come posso installare Instantbird su Linux?

    Extract the content of the downloaded archive, and launch the file named "instantbird". If a popup dialog asks you if you want to edit or launch the file, select "launch".

    We currently only provide 32-bit builds. In order to run these on a 64-bit system, you will have to install the 32-bit compatibility libraries provided by your distribution. For example, on Ubuntu, install the package ia32-libs by running sudo apt-get install ia32-libs from the command line.

    Instantbird è portatile (usabile da una chiavetta USB)?

    Se lanci Instantbird da una chiavetta USB, salverà il tuo profilo sull'hard disk del computer per impostazione predefinita.

    Puoi impostare Instantbird per salvare il tuo profilo sulla chiavetta USB usando l'opzione -profile da riga di comando.

    Per fare questo, clicca con il tasto destro sul file instantbird.exe e seleziona "crea scorciatoia", poi nelle proprietà della scorciatoia, aggiungi -profile ./foldername dopo "instantbird.exe".

    Aggiornamento

    C'è qualcosa che devo fare per usare sempre l'ultima versione di Instantbird?

    No, Instantbird si connetterà periodicamente per verificare che ci siano aggiornamenti e ti chiederà il permesso per installare una nuova versione, se questa viene trovata.

    Se questo non ti piace, puoi sempre cambiarlo nella finestrra delle preferenze.

    E se voglio aggiornare subito?

    C'è una voce di menù Controlla aggiornamenti (accessibile dal menù Aiuto) che ti permette di aggiornare subito Instantbird, senza attendere il controllo periodico.

    Posso installare una nuova versione sopra una installazione esistente?

    Si.

    I miei componenti aggiuntivi funzioneranno sempre dopo l'aggiornamento?

    I componenti aggiuntivi compatibili funzioneranno sempre. Se un componente non è più compatibile con la nuova versione di Instantbird, Instantbird ti proporrà di controllare se esiste una versione più recente del componente e di aggiornarlo.

    Se il tuo componente non funziona più dopo un aggiornamento, contattane l'autore per sapere se sta lavorando per aggiornare il componente..

    Disinstallazione

    Come posso rimuovere Instantbird?

    Su Windows, se hai usato il pacchetto auto installante, puoi disinstallare Instantbird dal pannello di controllo come disinstalleresti un qualsiasi altro programma.

    In tutti gli altri casi, puoi semplicemente eliminare la cartella di Instantbird.

    La rimozione di Instantbird non eliminerà i tuoi account, lo storico delle conversazioni, le estensioni e gli altri componenti. Questi dati sono salvati nella tua cartella di profilo.

    Ogni versione di Instantbird che installi successivamente continuerà ad usare i dati presenti in quella cartella.

    Uso

    Posso usare più di un account per volta?

    Si, ti puoi connettere contemporaneamente a più di un account del tipo supportato da Instantbird.

    Usa la Gestione account (accessibile dal menù Strumenti) per aggiungere un altro account.

    Quali protocolli sono supportati?

    Currently Instantbird supports by default: AIM, Bonjour, Facebook Chat, Gadu-Gadu, Google Talk, Groupwise, ICQ, IRC, MSN, MySpaceIM, Netsoul, Odnoklassniki, QQ, Simple, Twitter, VKontakte, XMPP, Yahoo and Yahoo JAPAN.

    Estensioni per protocolli addizionali possono essere installati come componenti aggiuntivi.

    Quando provo a connettermi a Facebook vierne visualizzato l'errore ID XMPP non valido. Qual'è il problema?

    Hai usato come username l'indirizzo email che usi per entrare nel sito web di Facebook. La chat di Facebook si aspetta che tu usi il tuo username univoco in questo campo. Vai su http://www.facebook.com/username/ per controllarlo.

    Quando provo a connettermi al mio account Facebook si presenta l'errore Non Autorizzato. Qual'è il problema?

    Devi abilitare le connessioni XMPP per il tuo account Facebook.

    1. Visita la Chat Facebook mentre sei dentro Facebook per abilitare l'accesso XMPP.
    2. Esegui la disconnessione dal sito di Facebook.
    3. Esegui di nuovo l'accesso al sito di Facebook.
    4. Connetti il tuo account Facebook dentro Instantbird ("Strumenti" > "Account" e clicca sul pulsante "Connetti" sul tuo account Facebook), dovrebbe completarsi con successo.

    Dove posso trovare i componenti aggiuntivi (estensioni e temi)?

    Puoi cercare i componenti dalla scheda Esplora della gestione componenti aggiuntivi (accessibile dal menù Strumenti) dove troverai alcuni componenti aggiuntivi raccomandati. Per vederne di più, puoi andare sul sito componenti aggiuntivi di Instantbird dove puoi anche sfogliare i componenti sperimentali e lasciare i tuoi commenti.

    Instantbird conserva la cronologia delle mie conversazioni?

    Si, Instantbird mantiene la cronologia per impostaizone predefinita. Usa le impostazioni nella scheda Privacy nella finestra Preferenze per configurarlo come preferisci. Se vuoi controllare la cronologia, usa il pulsante Mostra cartella cronologia... nella stessa scheda.

    Dove è conservata la cronologia?

    Il nome ed il percorso dei file di cronologia sono i seguenti: percorso del profilo/logs/protocollo/nome contatto o conversazione/data e ora.txt (sostituisci le parti in corsivo con i valori reali).

    Dov'è la cartella del mio profilo?

    Si trova in una delle seguenti posizioni, a seconda del tuo sistema operativo:

    Windows%appdata%\Instantbird\Profiles\ (copia e incolla esattamente questo in Windows explorer)
    Mac OS X~/Library/Application Support/Instantbird/Profiles/
    Linux (Unix)~/.instantbird/

    Ogni versione di Instantbird che installi successivamente continuerà ad usare i dati presenti in quella cartella.

    Posso accedere a about:config per specificare meglio le mie preferenze?

    Anche se lo sconsigliamo, about:config è accessibile dalla scheda Avanzate della finestra delle preferenze.

    Sviluppo

    Perchè sviluppate Instantbird?

    Ti diamo Instantbird perchè crediamo che la messaggistica istantanea sia una parte importante della tua vita in rete.

    Con quale licenza è rilasciato Instantbird?

    Instantbird is licensed to you under the terms of the GNU GPL license version 2.0 or later (because it uses libpurple which is GPL licensed). However, most of the source code is also licensed with the Mozilla Public License (MPL), version 2.0.

    Dov'è il codice sorgente?

    Un archivio con il codice sorgnete di ogni versione rilasciata è disponibile alla pagina pagina di download. L'ultima versione del codice in sviluppo può essere scaricata dal nostro archivio Mercurial seguendo le instruzioni per la compilazione.

    Chi fa Instantbird?

    Siamo una piccola squadra di persone molto motivate, ma speriamo che molti altri, insieme a te, si uniranno a noi per rendere questo progetto ancora migliore.

    Mozilla è sponsor del progetto?

    La fondazione Mozilla non ci ha aiutato finanziariamente.

    Il logo "Basato su Mozilla" sul nostro sito significa che Instantbird è basato su codice e tecnologie sviluppate dalla comunità Mozilla. Siamo molto riconoscenti verso tutta la comunità Mozilla per le fantastiche tecnologie sulle quali Instantbird è basato.

    Come posso contribuire?

    Ci sono molti modi di entrare a far parte del progetto. No c'è bisogno di essere un programmatore di computer per aiutarci. There are several ways to take part in the project. You don't need to be a computer programmer to help us. Vai a See partecipa per maggiori dettagli.

    Posso aiutarvi traducendo Instantbird nella mia lingua?

    Si! Vai alla pagina wiki delle traduzioni per maggiori dettagli.

    Come posso creare componenti aggiuntivi?

    Leggi la pagina wiki delle estensioni.

    I componenti aggiuntivi per Firefox/Thunderbird funzionano con Instantbird?

    Non automaticamente, ma la maggior parte può essere adattata. Leggi la pagina di adattamento componenti di Firefox.

    Come posso seguire l'attuale sviluppo?

    Per rimanere informato su importanti novità sullo sviluppo, probabilmente vorrai seguire il nostro blog.

    Se vuoi seguire le nostre discussioni, ti invitiamo ad unirti alla nostra chat su IRC: #instantbird sul server irc.mozilla.org.

    Le Versioni "nightly" vengono pubblicate ogni giorno affinchè tu possa seguire e lo sviluppo e collaudare le nuove funzionalit che sono state aggiunte di recente. Sentiti libero di usarle, ma attento! Possono essere instabili e, se decidi di usarle, ti preghiamo di farlo per aiutarci a provare le future funzionalità, non solo per avere l'ultimo giocattolino a tua disposizione. Quindi se trovi un bug, per favore segnalalo (Inviando un bug come si deve invece di lamentarti).

    Cosa ci sarà nella prossima versione?

    Leggi la roadmap.

    Quando uscirà la nuova versione?

    Siamo molto coinvolti in questo progetto e compiaciuti che tu condivida con noi il desiderio di andare avanti il più velocemente possibile. Comunque, vista la natura dello sviluppo del software, ci possono essere problemi a rispettare le scadenze. Consideriamo infatti la qualità più importante della velocità di rilascio.

    Instantbird supporterà il trasferimento file, le chat video, la mia funzione preferita?

    Leggi la roadmap.

    Sentiti libero di discutere con noi le cose che non sono elencate per sapere se possono essere implementate come componente aggiuntivo.
