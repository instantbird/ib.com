Requisiti di sistema

I seguenti sono i requisiti di sistema minimi necessari per usare Instantbird.

Windows

  • Sistemi operativi: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128MB di RAM
  • 50MB di spazio sul disco

Mac

  • Sistemi operativi: Mac OS X 10.6 (Snow Leopard) e successive
  • 256MB di RAM
  • 100MB di spazio sul disco

Linux

Instantbird ha bisogno almeno delle seguenti librerie per funzionare su Linux:

  • GTK+ 2.18 o superiore
  • GLib 2.22 o superiore
  • Pango 1.14 o superiore
  • X.Org 1.0 o superiore
  • libstdc++ 4.3 o superiore

Ricorda che i distributori di Linux possono fornire dei pacchetti per la tua distribuzione che hanno requisiti diversi.
