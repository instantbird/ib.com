Systémové požadavky

Následující požadavky jsou minimální potřebné pro běh Instantbirdu.

Windows

  • Operační systém: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128MB operační paměti
  • 50MB volného místa na disku

Mac

  • Operační systém: Mac OS X 10.6 (Snow Leopard) a novější
  • 256MB operační paměti
  • 100MB volného místa na disku

Linux

Instantbird vyžaduje alespoň následující knihovny pro běh na Linuxu:

  • GTK+ 2.18 nebo vyšší
  • GLib 2.22 nebo vyšší
  • Pango 1.14 nebo vyšší
  • X.Org 1.0 nebo vyšší
  • libstdc++ 4.3 nebo vyšší

Pro různé linuxové distribuce se mohou uvedené požadavky lišit.
