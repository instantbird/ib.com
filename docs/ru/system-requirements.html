Системные требования

Ниже приведены минимальные системные требования, необходимые для запуска Instantbird.

Windows

  • Операционные системы: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128МБ оперативной памяти
  • 50МБ свободного пространства на жестком диске

Mac

  • Операционные системы: Mac OS X 10.6 (Snow Leopard) или выше
  • 256МБ оперативной памяти
  • 100МБ свободного пространства на жестком диске

Linux

Для запуска на Linux Instantbird требуются по меньшей мере следующие библиотеки:

  • GTK+ 2.18 или выше
  • GLib 2.22 или выше
  • Pango 1.14 или выше
  • X.Org 1.0 или выше
  • libstdc++ 4.3 или выше

Пожалуйста, обратите внимание, что дистрибьюторы Linux может предоставлять пакеты для вашего дистрибутива, которые имеют другие требования.
