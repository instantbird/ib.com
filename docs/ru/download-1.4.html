Загрузить исходный код

Так как Instantbird является проектом с открытым исходным кодом, вы можете свободно загрузить исходный код и изменить его.

Что нового?

  • Средство просмотра логов теперь группирует ваши разговоры по дате.
  • Улучшена поддержка Твиттер
    • Счетчик символов для Твиттер теперь учитывает автоматическое сокращение ссылок, позволяя вам легко твитить ссылки, не беспокоясь об их длине!
    • Произведено обновление до Twitter API v1.1. Обратите внимание, что Instantbird 1.3 может перестать работать с Твиттером начиная с 11 июня 2013 года!
    • Твиттер теперь включает всех, кого вы читаете, в качестве участников вашей хронологии.
  • Улучшена работа IRC-аутентификации с боунсерами (например ZNC).
  • Теперь вы можете легко проигнорировать предупреждения о самоподписанных/некорректных/истёкших сертификатах для серверов IRC.
  • Каждая учетная запись теперь хранит логи отладки, который можно получить, щёлкнув правой кнопкой мыши по учётной записи в Окне управления учётными записями и выбрав пункт "Копировать лог отладки". Они содержат важную информацию для разработчиков, помогающую им диагностировать проблемы у пользователей. (Обратите внимание, что логи отладки МОГУТ содержать конфиденциальную информацию).
  • Под капотом
    • Обновление движка: Instantbird 1.4 создан на основе Mozilla 20.0.1 и использует libpurple 2.10.7!
    • Mac OS X < 10.6 более не поддерживается. Пожалуйста, обновите свою операционную систему или продолжите использовать Instantbird 1.3.
  • И многое другое... Для получения информации обо всех изменениях в коде, произошедших с момента выхода Instantbird 1.3, прочтите полный список изменений.
