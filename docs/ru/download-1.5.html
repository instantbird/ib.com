Загрузить исходный код

Так как Instantbird является проектом с открытым исходным кодом, вы можете свободно загрузить исходный код и изменить его.

Что нового?

  • Упрощено открытие новой вкладки с беседой.
    • Щелчок по кнопке '+' в окне бесед отобразит список собеседников, которые могут быть запущены всего одним щелчком.
    • Список сортируется по алгоритму frecency, учитывающему, как часто и насколько недавно вы разговаривали с каждым контактом.
    • Этот список также автоматически включает список каналов, отправляемый IRC -серверами, к которым вы сейчас подключены.
  • Улучшены всплывающие подсказки, которые теперь лучше соответствуют стилю, используемому Instantbird
  • Улучшен интерфейс Многопользовательских чатов:
    • У каждого участника теперь имеется контекстное меню, которое позволяет открывать с ним приватные беседы или добавлять его в список друзей.
    • Подсвеченные псевдонимы в комнатах чатов теперь имеют подсказки и контекстные меню.
  • Чаты, к которым производится автоматическое присоединение и которые были поставлены на hold, останутся поставленными на hold и после перезапуска.
  • Добавлена возможность настройки альтернативных псевдонимов для IRC, в случае, если предпочитаемый вами псевдоним окажется уже занят при подключении.
  • Страницы about: (например, about:config) теперь можно легко открыть с помощью команды /about (например, /about config).
  • Добавлена поддержка дисплея Retina на Mac OS X.
  • Пользователи Google Talk и Android Hangouts теперь отображаются со значком мобильного телефона.
  • Пользователи Google Hangouts больше не будут выглядеть как всегда набирающие текст.
  • В беседах улучшена поддержка отображения RTL языков.
  • Удалена поддержка протокола ВКонтакте, так как служба ВКонтакте прекратила поддержку подключения с помощью клиента XMPP.
  • Новости для разработчиков: Добавлен новый API для добавления панелей вкладок с произвольным содержанием в окнах бесед: документация в коде.
  • Движок обновлен до Mozilla 25.
  • Устранены разные мелкие ошибки и несколько багов приводящих к падениям.
  • И многое другое... Для получения информации обо всех изменениях в коде, произошедших с момента выхода Instantbird 1.4, прочтите полный список изменений.

Известные проблемы:

  • Пользователям NVDA необходимо обновиться до 2014.1, чтобы обойти ошибку в платформе Mozilla, приводящую к тому, что при прокрутке списка контактов выводится сообщение "Неизвестно".
  • Щелчки по ссылкам не работают в некоторых новых дистрибутивах Linux. Чтобы обойти эту проблему, откройте about:config (наберите в беседе /about config), найдите параметры network.protocol-handler.warn-external, и установите все их значения в true. После щелчка по этим ссылкам вам будет предложено выбрать программу для их открытия. Подробнее в ошибке 1995.
