Requisitos del sistema

Los siguientes son los requisitos de sistema mínimos necesarios para ejecutar Instantbird.

Windows

  • Sistemas operativos: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128MB de RAM
  • 50MB de espacio en disco duro

Mac

  • Sistemas operativos: Mac OS X 10.6 (Snow Leopard) y posterior
  • 256MB de RAM
  • 100MB de espacio en disco duro

Linux

Instantbird necesita al menos las siguientes bibliotecas para ejecutarse en Linux:

  • GTK+ 2.18 o superior
  • GLib 2.22 o superior
  • Pango 1.14 o superior
  • X.Org 1.0 o superior
  • libstdc++ 4.3 o superior

Por favor, ten en cuenta que las distribuciones Linux pueden proporcionar paquetes con distintos requisitos.
