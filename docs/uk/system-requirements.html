Системні Вимоги

Нижче наведені мінімальні системні вимоги, необхідні для запуску Instantbird.

Windows

  • Операційні Системи: Microsoft Windows XP SP 2, Windows Server 2003, Windows Vista, Windows 7, Windows 8
  • 128МБ ОЗУ
  • 50МБ вільного місця на жорсткому диску

Mac

  • Операційні Системи: Mac OS X 10.6 (Snow Leopard) та пізніші
  • 256МБ ОЗУ
  • 100МБ вільного місця на жорсткому диску

Linux

Instantbird потребує принаймні наступні бібліотеки для роботи під Linux:

  • GTK+ 2.18 або новіше
  • GLib 2.22 або новіше
  • Pango 1.14 або новіше
  • X.Org 1.0 або новіше
  • libstdc++ 4.3 або новіше

Зверніть увагу, що дистриб'ютори Linux можуть надавати пакунки для вашого дистрибутиву, які мають інші вимоги.
